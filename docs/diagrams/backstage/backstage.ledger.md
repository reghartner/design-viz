Scope: the platform lifecycle requested by the operator: catalog-seeded authoring, published service associations, GitHub scanning and human decisions, with the related reference-trace/incident proposal loop. Installation commands, deployment-specific credentials and exhaustive field catalogs remain in linked source documents; this is a process guide, not a replacement API reference. Numerical app-rehearsal fixtures are not part of the platform lifecycle.

Presentation: eight tabs / nine diagrams; state, table, checks and log panels describe authored example outcomes. Custom edge kinds name documented actions or conceptual handoffs, not invented wire protocols. Animation timing is presentation-only. Gate refusal uses blocked delivery only when the acceptance write is not attempted; a rejected Git write is described as a received refusal. No invented service metrics, company identities, SHAs or runtime diagnoses are used.
