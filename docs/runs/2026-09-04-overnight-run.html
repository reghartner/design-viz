The authoring path, as it now stands

  • Design doc's mermaid block → tools/mermaid2spec.py → skeleton spec
  • LLM agent + contract/authoring-contract.md enriches: prose facts, icons, permalinks, panels, steps
  • node tools/validate.js spec.json — field-path errors + lint warnings, no browser needed
  • python3 tools/inject.py spec.json template/flowview.html out.html — finished page
  • Meeting feedback in plain English → agent edits the JSON → re-inject → republish same URL

Honest gaps

  • Spec diff view (visual before/after of two spec versions) not built — logged as planned in CHANGELOG.
  • Generated doorbell page vs the hand-built one: generic typed widgets instead of circuit-board art; simpler scene walk-in; no interrupt-line flare.
  • Inspector panels render in declaration order, single column — no per-panel layout control yet.
  • Containment-group members must sit adjacently; the boundary is a bounding box, not a layout constraint.
  • Widget catalog still unbuilt: power Sankey, day-strip timeline, clip-retention lifeline, duplex audio meter, ring buffer, spectrum, geo scatter.
  • Repo is private; making it public is your call.
