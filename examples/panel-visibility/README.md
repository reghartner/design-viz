# Panel visibility

Open `panel-visibility.spec.json` in the workbench, or open the generated HTML.
The phone starts hidden. Notification delivery shows it and hides the camera;
the review step brings the camera back. The offline path never shows the phone.

Select a step → Inspect → Panel changes → Panel visibility to change Show, Hide,
or Inherit. Select a panel through Outline to change Starting visibility even
when the panel is hidden. Hidden panels keep their space and their contents;
Ambient shows every panel included in the current view.
