# Shared icons and company branding

Open [the standalone story](shared-icons.html) or load [the spec](shared-icons.spec.json) in the workbench.

Five authored steps show normal power, charging, a monitoring alarm, a thermal pause and recovery. Colored icon shapes distinguish each state. A diagram-level Cedar Home brand is inherited by Device App, Camera and Security monitoring. Replace its icon with an uploaded company logo in **Inspect → Company branding**.

This is an illustrative story, not a claim about any product. See [the shared icon guide](../../docs/shared-icons.md) for the contract and extension API.
