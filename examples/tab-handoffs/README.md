# Two diagrams, one spec

Open [tab-handoffs.spec.json](tab-handoffs.spec.json) in the workbench, or export
it with `tools/inject.py` and the freshly built `template/flowview.html`.

Follow **Delivery →** from **Order intake** to **Delivery pipeline**. Advance
its steps, then use **Back to Order intake**. Each diagram keeps its reading
position. The second diagram also has an **Order intake →** handoff for a
reciprocal route. In the workbench, click the arrow tip to preview navigation;
click the node body to edit it.

This is a fictional process illustrating navigation, not a delivery contract.
