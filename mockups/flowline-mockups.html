Aurora

ambient live traffic

Dark ground, glowing paths, packets always in motion. Reads as a running system — the motion tells you flow direction before you read a single label. Colors here are keyed to path role (command / auth / ack) rather than protocol; mockup 04 above replaces that with the protocol legend.

  • Where it fits: dark-themed docs, architecture overview pages, anything meant to impress on first open.
  • Motion: marching dashes on every path plus glowing packet dots (SMIL animateMotion), running continuously.
  • Cost: pure CSS + SVG, zero JavaScript. Heaviest visual, calmest to maintain.
02

Daylight

print-friendly documentation

Calm paper ground and one color per path role: indigo command path, amber auth branch, teal acknowledgment. Slow dash drift and a few sparse packets — enough motion to show direction, not enough to fight the prose beside it. Prints legibly.

  • Where it fits: inline next to reference prose, runbooks, PDFs, printed handouts.
  • Motion: slow dash drift on the command path, four staggered packet dots. Quietest of the three.
  • Cost: pure CSS + SVG, zero JavaScript. Path-role colors double as a legend.
03

Playhead

self-narrating walkthrough

The diagram narrates itself. One step is lit at a time — its edges, nodes, and step number turn green, a packet runs the edge once, and the caption bar states what is happening. Auto-advances every three seconds; the reader can pause, step, or jump. Strongest for onboarding and incident-runbook docs where reading order matters.

STEP 1/7
  • Where it fits: onboarding guides, protocol walkthroughs, runbooks — anywhere the sequence is the lesson.
  • Motion: one lit step at a time; a single packet runs the active edge, then freezes at the arrowhead.
  • Cost: same SVG as the others plus ~40 lines of JavaScript for the stepper.
Build notes. All four boards are generated from one shared geometry (nodes, edges, labels, step coins) — only the CSS skin, the edge-kind table, and the packet schedule differ per mockup. Motion is CSS stroke-dash animation plus SMIL packets; no libraries. The reduced-motion preference disables packets, dash motion, and autoplay.
