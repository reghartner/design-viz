# Optional physics package

This package contains the `wavefield` and `forcebody` teaching panels, the
**Waves & forces** starter and complete story, and its physics recipe and
contract. It is independent of the biology-focused science package.

Enable it in a company or site config with `"packages": ["physics"]`, or
preview locally with `python3 tools/build.py --package physics`. The viewer,
editor, validator, and offline agent kit use the same package selection.

Start with the [physics recipe](cookbook/physics-panels.md). It explains the
idealized models, authored controls, and desktop review loop. Workbench and
document editing are desktop only.
