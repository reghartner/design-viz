The story moves through four teaching arcs:

2. **[Sell the inventory →](../sell-the-inventory/README.md)** (45 steps): on-sale day, demand-based pricing, heritage-night links, and the difference between an offer for the first 10,000 fans and one for everyone.
3. **[Serve and learn from game night](../serve-game-night/README.md)** (58 steps): ticket ownership versus attendance, gate stock, a score-first sponsor offer, and the morning-after recap.
4. **[Build the next season](../build-next-season/README.md)** (25 steps): the path from a friend's ticket to membership, then the clinch-or-fade renewal fork.
