FLOWVIEW FIELD GUIDE

Make the system make sense.

A practical guide to building diagrams people can follow.

01 / YOUR FIRST DIAGRAM

Start with a small, complete story.

Flowview combines a system diagram with a sequence of events. The diagram shows who is involved; steps show what happens; panels show what changes for people and devices.

  1. Open a useful starting point. On the home page choose Start new project → Simple service flow. Or choose Blank diagram if you want to start empty.
  2. Make the actors yours. Click a node in the preview. In Inspect, change its title and sub (the one-line detail). Press Enter or leave the field to apply it.
  3. Add something. Choose Add to diagram → Node, then click a preset to add it. The Section selector chooses the destination section.
  4. Connect the actors. Alt/Option-click the source node, release the key, then click the destination. Give the new connection a meaningful label, such as “Request recording.”
  5. Walk through it. Open Steps. Select a step, then Inspect selected step to edit its caption. Add another with Append step. Use ADD TO STEP to choose the nodes and connections active at that moment, then finish the mode.
  6. Keep a copy. Choose save in the editor’s file controls to save the editable JSON. Use export… when you want a viewable HTML page too.
Build one happy path first. Get the starting event, meaningful changes, and outcome right. Then add failure paths and a second view for another audience.

02 / FIND YOUR WAY

Preview on one side. The selected thing on the other.

Click a node, connection, panel, or step to inspect it. Inspect edits the selection, Steps manages the story, and JSON exposes the complete source. You can do ordinary editing without writing JSON. If you do edit JSON, choose Render and read any validation messages.

Inspect → Document settings edits the title and Saved default skin for the whole document. Under Source document, add a source URL, then its description, version and date to show a “Generated from” line below the title. Clearing the URL removes that line. Save and Export carry these settings; each edit supports Undo. A bare diagram offers Add document settings to wrap it in a page first. The same settings are available from Outline → Document settings. Under Advanced: reader tour and compatibility, you can edit a custom reader tour as JSON with validation; clearing it restores the built-in tour. The runtime and feature requirements are read-only, managed by Save and Export.

Canvas appearance is a temporary skin preview. Its status shows the preview and saved default separately. Use document default previews the saved choice, while Edit saved default… opens Document settings. A hosting site can still choose its own skin.

To start a section with its paragraphs and bullets folded, select its heading and check Initially collapse prose. The diagram and contract blocks stay visible. Readers can expand the prose; their toggle does not change the saved starting state.

Inspector actions sit above their fields. Collapsible sections start closed under muted headers with chevrons; click a header or focus it and press Enter to open it. Groups stay open while you edit the same object. Ordinary fields save as edited. Diagram handoff and Domain detail have an Apply button at the top of their open group. Extraction keeps Download, Apply extraction, and Cancel above its settings and preview. Separate destinations must be downloaded before Apply is enabled. List Add buttons start the list; remove and reorder stay with each item.

Page
The whole document, with one or more sections and optional tabs.
Section
One diagram, its panels, and its timeline.
Node / connection
An actor and a directed communication between actors.
Step / path
A moment in the story and the sequence of moments for an outcome.
View
An arrangement of the same section for an audience. It can show fewer panels and fewer stops.

The left rail opens Inspect, Steps, Outline, JSON, or File beside it. Each fills the editor; the preview stays on the right. Drag the visible divider right for more editing room. File → Workspace preferences contains starting editor arrangements, Focus workspace, and Reset panel layout. Story with an agent opens Agent; Engineering review opens Brief and Inspect; Canvas only closes the tools. These change editor windows, not diagram views. The top toolbar keeps Add to diagram, Undo, Redo, User guide, and Download JSON available. Use Outline (⌘/Ctrl K) to find objects across sections and tabs. Canvas selection updates Inspect without switching away from another tool.

The Flowview wordmark and ← New / open return home. Browser Back and Forward work between entry screens and the editor. Continue brings back your current project.

03 / NODES & CONNECTIONS

Arrange the actors. Make each connection explain itself.

New nodes start with Free placement, including catalog nodes and nodes in new sections or detail flows. Drag them anywhere; their saved positions stay fixed when connections change. Rows keep nodes ordered left to right. Drag a node to another row or position to reorganize the flow. For arbitrary placement, select the node and choose float → Free placement, then drag it anywhere or adjust Float X / Y. Choose an automatic float position or return it to rows when you want automatic placement again.

To arrange several floats, Shift-click each node in the same section, then choose Align horizontal (same Y) or Align vertical (same X) in Inspect. The first selected node sets the alignment. Drag any selected node to move the whole selection together; Shift may stay held. Each alignment or group move is one Undo action. For nodes in rows, choose Free placement first.

Edge routing belongs to the whole diagram. Select its section heading or Outline entry, then choose Inspect → Edge routing → No lanes (default) or Lanes. New projects, built-in templates, catalog seeds and trace imports start without lanes. Opening an existing spec preserves its setting. Lanes reserve connector tracks between rows and require 1–5 unstacked nodes per row, no floats or self-loops; other layouts use curves. This is separate from the story lane labels on steps.

To draw a connection, Alt/Option-click a source, then click a destination. You can also use Connect from this node in the inspector, or Add to diagram → Connection. A preview arrow shows where you are connecting. Esc cancels. Connections stay within a section; an existing ordinary connection is not duplicated.

Select the connection to edit its label, Connection type, and arrow behavior. All built-in protocols are available. Use New connection type… for a custom name/color; creation also assigns it to this connection. Edit connection type updates its name/color everywhere in the document. Step inspectors provide the matching Story lane and New lane… controls. Display-name edits preserve IDs and advanced palette colors; setting a color replaces that palette. Exit side and Entry side choose its attachment edges; the position percentage moves an endpoint along that side. Use these when automatic routing obscures a relationship.

Shape an arrow directly: drag its line or a round handle to pull a smooth curve through that position. Drag another part of the arrow to add a point and make an S-curve. Double-click a point to remove it, or focus it and press Delete. Arrow keys move a focused point; hold Shift for fine adjustments. Endpoints stay attached when nodes move. Reset curve in Inspect restores automatic routing. Each drag is one Undo action; Escape cancels a drag. Manual curves keep your chosen shape, so check that they clear nearby nodes.

Use the toolbar’s Section selector to choose a section, then Add to diagram → Paragraph or Bullet point to start writing, even in a section without a diagram. Add appends to the section’s paragraphs or top-level list, opens the page view, and selects the new text for typing. You can also select an empty section heading and choose Add an introduction or Add first point in Inspect. Click a paragraph to edit it; Add paragraph before/after, Move paragraph up/down, and Delete paragraph manage its position. Click any bullet or subpoint to edit it directly. Add sibling and Add subpoint grow the list; Indent, Outdent, and Move point up/down move the whole subtree in one undoable edit. delete bullet removes the selected point and its children. Undo and Redo restore each addition, deletion, or move. The Outline includes every nested point. Step text, paragraphs, bullets, contract notes and glosses, change notes, and notification messages support Markdown. Their textareas offer Bold, Italic, Code, Code block, and a URL field with Insert link. Select text before formatting. For bullet lists, start each line with - , * , or + ; indent sub-bullets by two spaces. A blank line ends the list. Enter and Tab keep their normal text-editing behavior.

Connections, bullets, and contract fields have Visibility by path position in their inspector. Choose Show from position and Hide starting at position, using the full story’s captions as a guide. These one-based positions apply on every alternate path, even if a view hides some stops; they stay in place when you reorder steps. Caption path previews the other path’s captions. The current-position buttons use the full path position. Ambient mode shows everything.

Fit width uses the available width; Readable preserves node readability and lets you pan horizontally when the board overflows. These controls change your viewing scale, not the authored node positions.

Give a large process its own detail. A node’s Create detail flow starts a drilldown into another section. Readers keep context through the overview map and breadcrumbs. In Domain detail, apply a local child section, then map When parent event to a Child path and Child event. Valid row edits save directly; Preview mapping opens the saved child position, even when that view normally hides the stop. Unset choices inherit the detail entry defaults. Imported numeric positions and advanced fields stay intact; Advanced mapping JSON remains available. Apply changed entry defaults before editing mappings. Choosing another child section or target type resets its entry position, mappings, and boundary ports; unrelated metadata is retained. To continue to a peer diagram on another tab, use Diagram handoff → This spec, choose its section, and Apply handoff. Readers click the arrow to switch tabs and use Back to … to return to their original step. Both diagrams keep their reading positions. Choose Separate document for an independently maintained process.

04 / STEPS & PLAYBACK

A step is a change, not a screenshot.

Use Steps to select, search, append, duplicate, or move beats earlier and later. A useful caption explains what changed and why: “The recording service stores the clip before notifying the resident.” Captions and prose support backticks for inline code and triple backticks for code blocks; node labels stay plain text.

ADD TO STEP selects the nodes, edges, and panels involved in a beat. Finish this mode before trying to edit or connect objects normally. Panel fields describe what changes at that beat. A value you do not change usually carries forward from earlier steps on the selected path. The Effective state · all panels inspector explains whether a value is initial, set here, inherited, or transient.

Use the numbered circles and previous/next controls to walk the story. Play starts automatic advancement; Pause holds the current beat. Under Playback settings, choose the opening view and whether it should autoplay. The editor starts paused even when the exported viewer is configured to autoplay. Ambient view animates the overall diagram; step view follows one path.

You can color an individual step circle to mark a phase change without making an alternate path. Use a branch only when the outcome or sequence actually differs.

Story time. When the story happens at a particular time, first decide its span: when it starts and when it ends. Select the section and open Story time and device defaults. Enter a Start such as 2026-09-24T22:30, optionally an End, and choose the Clock (12-hour or 24-hour) and Date format. Then select a step and set its Story time: +45m moves forward from the previous step, 06:50 jumps to the next 6:50, and a full date-time sets it exactly. Leave it empty to keep the previous step’s time. The note underneath shows the resolved time on the selected path. Phone, Device app and App screens clocks and dates follow the step automatically; a clock or date you type on a panel still wins at that step until the story time next moves. Clear Start to turn story time off.

Batteries drain with the elapsed story time and charge while their trend is charging. Ask the device owner or check the source for the real rates, then set diagram-wide Drain %/h and Charge %/h under the same section group, or override them on a Battery panel. Empty rate fields show the built-in default (placeholder): it keeps a sketch moving but is not a fact about your device. If you keep it, say on the page that the battery is an illustrative estimate. New battery panels start with the diagram’s rates. In a step’s battery changes, Extra drain % subtracts a one-time cost such as a recorded clip, and charge sets a known reading from which the drain continues. Effective state labels these values Story time or Story time · battery drift, adding built-in default rate when a placeholder rate is in use. Device app battery cards show what the app last received; set them at the step the report arrives.

Report times. Don’t type “Updated just now” or “Updated 3 h ago” into a Device app card: it will be wrong a few steps later. Instead, on the step where the app receives new data, open that card under Panel changes, set its value and press Reported at this step (in Starting state the button reads Reported at story start). On every later step the card works out its own text from the story time: Updated just now, Updated 5 min ago, Updated 3 h ago, and Last report with the date and time after a day. The Report time box also takes -15m (15 minutes before this step), 06:05 (the latest 6:05 at or before this step) or a full date-time. Clear report time stops the computed text from this step on, even when the report came from an earlier step; Inherit removes this step’s report time so the earlier report applies again. In the panel’s fields table, set a card’s freshness to absolute to show “Last report 6:05 PM” instead, or off to keep your own text. Text you type in detail still wins until the next report. Freshness never marks a card Cached; choose that status yourself. Effective state labels the computed text Story time · derived freshness. Without a story start, report times are ignored.

05 / ALTERNATE OUTCOMES

Show where the same story goes differently.

An alternate belongs on the same diagram: a dropped signal, a retry, a rejected request, or a recovery. Keep the common lead-in shared, then show the first different event.

Happy path1234
Recovery1234
Shared ending5

Shared beginning → independent outcome → one shared ending

  1. Select the last shared step in the Steps tab. If the first different event is step 3, select step 2.
  2. Choose + Alternate after selected step. The first branch creates a happy path and an orange alternate. Rename the alternate to its outcome and set its color with Update path.
  3. Edit the new independent step, then append what happens next. An alternate can end early; it does not need as many steps as the happy path.
  4. To rejoin downstream processing, use Reuse steps… → Use shared steps for the common operations. They appear once on a common track, with connecting lines showing the join. Add independent events afterward to split again, and share later events to rejoin. A shared ending means every participating path finishes there. Use Copy and customize when events should evolve separately.
Shared means one editable event. Editing a shared step changes it in every path that uses it. Choose Make independent here before making a path-specific change. A common track shows shared downstream operations. Shared beginnings can appear as faded circles. A matching caption alone does not make two steps shared.

Clicking a path chip starts at step 1, including its shared lead-in. Clicking a shared circle keeps the selected path if it participates; otherwise the circle identifies the path it will select. Its numbers and state follow that path. A retry flag or earlier log entry carries through shared operations unless a step changes it. An early-ending path never joins a later block it does not visit. Hiding stops in a view does not change the authored joins or endings. Represent a communication that fails with Add failed communication on that step; make the edge visibly break and explain the consequence. Do not animate a successful delivery that never happened.

Remove from this path only removes membership. Delete from all paths removes the event everywhere. Read the affected paths before deleting a shared step.

06 / VISUAL PANELS

Show the consequence outside the arrows.

Choose Add to diagram → Panel. The large picker shows a preview and description; select one, then explicitly add it. Pick panels that answer a question, rather than filling every slot.

To replace a panel, select it and choose Change panel type…. Choose a different type in the library, then Review replacement. The review lists setup and step overrides that will be removed across every path, plus any playback controls that must detach. Copy original JSON keeps a backup. Replace panel starts the new type from its template while keeping its ID, title, visibility, placement, and centerpiece setting. Company branding is kept when the new type supports it. Step visibility and path membership stay intact; author new panel-state changes after replacement. Cancel makes no change, and one Undo restores the original.

  • Home shows people, rooms, cameras, doors, and physical activity.
  • Screen and device app show video clips, notifications, battery or camera data. Resize its layout tile to scale the phone, text, and cards together. Device app stays in a phone frame: choose its Starting phone screen, then use each step’s Phone screen control to move between Home screen and Device app. Under Starting state, set each card’s value, status, detail, and Card visibility. Hide cards that appear later. Each step’s Card visibility control shows or hides a card while keeping its data. Use Notifications → Add notification to write its App, Title, and Message. Reorder or remove cards in the composer; its preview shows your text. Clear earlier notifications clears the old stack before adding this step’s cards. Starting state supports the same composer for Phone and Device app. Notifications and card values carry independently of screen changes. Data sources are optional; add them when explaining where a value comes from.
  • Monitoring and dispatch connect an operator’s video review to an emergency response.
  • Messaging cost comparison compares two delivery routes with stacked bars and matching engineering components. In Inspect, choose Display density → Auto to fit the panel, Compact for short horizontal bars, or Expanded for vertical bars. Set One-way messages in Starting state or a step; Following route highlights the route being explained. Expand Rates, assumptions & tradeoffs for the price details. Start with the Messaging cost tradeoffs template and its Compact comparison view. Replace its illustrative rates and describe your assumptions before using it for a decision.
  • Software and telemetry panels make queues, database delays, logs, gauges, and other state visible. Browse the picker for the available types.

Click the icon field’s preview and name to see colored choices, search names, or filter by category. This works for nodes, groups, Home elements and Device app cards. In Device app, set a card’s default under fields → icon; use its Starting state → icon or a selected step’s Panel changes → card → icon to show a different state such as charging. Icon choices carry independently of values and freshness. Inherit removes the selected step’s assignment and uses the earlier path state.

To reuse a company name and logo, select a Phone, Device app, Camera screen or Security monitoring panel and expand Company branding. Choose Shared across this diagram to edit every inheriting panel at once, Override for this panel for a local variation, or No brand on this panel. Enter Company / app name and choose a Library icon, a short Monogram, or Upload logo. Uploads accept PNG, JPEG or WebP up to 512 KiB and 4096 × 4096 pixels. Logos travel with the saved file. A local mark replaces the shared mark.

Select a panel and open Starting state to set its initial values with the same typed controls used by steps. This is available for cameras and app screens as well as state chips, gauges, queues, thermometers, batteries, lifecycles, waterfalls, status lights, connections, device fleets, dispatch and security monitoring. The assignment selector beside a field says what its value means: Use panel default in Starting state, Inherit previous in a step, or Set value. Some fields also offer a named reset such as Use declared icon. The note under a step field shows its effective value and where it came from. These values begin every path; edits here preserve step overrides. Set the panel’s starting values, then change only what matters in each step. Recording and scene activity are separate: a camera can start recording before a person enters the scene. Advanced JSON remains available for imported or uncommon values.

Checks, budgets, tables and logs have typed controls in Starting state and step changes. Checks and budgets show one entry per declared check or metric. Their values form a complete snapshot; entries left out use their defaults. Table rows let you add, reorder and remove records, with a type for each cell; removing every row clears the table. Log events append at the selected step, so an empty list adds nothing and does not erase earlier events. Choose Inherit previous to remove a step assignment, and use Advanced JSON for uncommon imported values.

In-flight, timelines, X-rays and buffers use controls that follow their playback rules. In-flight has no Starting state: start, finish and outcome rows happen only at the selected step. Timeline events and missed beats append without erasing earlier markers. X-ray layer choices and a Buffer’s complete cell row save snapshots; Buffer paint ranges accumulate until a later complete snapshot replaces the base. App screens uses the same explicit assignment choices for its starting screen, date and time while keeping image upload and per-step screen controls together.

To hide an entire panel until it matters, select it and set Starting visibility to Hidden until a step shows it. Then select a step in the Steps tab, open Inspect, and use Panel changes → Panel visibility. Every panel has Show, Hide, and Inherit. Show and Hide carry forward on that path; Inherit removes this step’s override. Hidden panels keep their space and continue receiving updates. Attached playback controls stay usable. Use Outline to select a hidden panel. Layout-hidden elements stay hidden; Ambient shows all panels included in the view.

Camera step fields and Phone audio have a duration selector. Enter a value, then choose Carry forward or This step only. Inherit previous state removes this step’s assignment. Audio changes replace the whole audio snapshot, rather than inheriting individual audio fields. If an imported patch has both a temporary and carried value, ordinary edits affect the temporary value and preserve what resumes afterwards; explicitly choosing a duration keeps the temporary value and replaces the pair. Starting state and notifications have their own behavior.

07 / A STORY AT HOME

Place the house once. Animate what happens there.

Start with A connected home to see rooms, actors, devices, and an outage together. Choose Edit layout on the Home panel to edit its shared house, rooms, devices, doors, and subjects. Expand an element’s collapsed inspector group to see its fields.

In Edit layout, expand a device or subject row and use the icon picker to choose its marker. Cameras and hubs keep their normal behavior when you change their icon. Leave the choice empty to keep the normal camera, router, sensor or person marker.

In shared layout mode, drag devices, doors, and people; use a room’s border or label to move it. The house grip moves its outline, and corner handles resize the house or rooms. Moving a room or the house outline does not move its contents. Outdoor areas can sit around the house or beside an indoor room.

For a marker that changes during the story, use Starting device and subject conditions for its initial icon, or the selected step’s Home at this step → element → icon. Choose Inherit previous icon to follow the earlier state, Restore layout icon to reset its marker, or a colored tile in the picker for a new choice. Icon changes preserve the device’s state and the subject’s position; show a hidden subject before changing its icon on that step.

Choose Edit home at current step to animate an event. This edits that moment instead of the shared floor plan. Use Inherit to remove an override and take the earlier path value. A device’s temperature and operating state are separate, so an overheated camera can remain visibly hot after shutting down.

Doors pivot at their hinge: width sets the leaf’s length, facing sets the closed direction, and swing sets its opening angle. Change the door’s state at the relevant step. Subject labels are off by default; enable them when names help. A cloud belongs under devices using the cloud icon; subjects are moving actors.

Keep time honest. “Recording begins,” “visitor walks away,” and “resident receives the clip” are often different steps. Give each its own visible change.

08 / LAYOUTS & AUDIENCES

One story. More than one useful view.

Choose Arrange section to position and resize the diagram, panels, and step controls. Use View name for reader-facing names such as “At home” and “Service flow.” Duplicate a view, then tailor it for another audience.

Choose View type → Standard for your authored arrangement or Explore for a full-height graph with independent floating panels and pinned step controls. Section paragraphs and bullets appear together in a floating Section notes window, with the diagram filling the canvas behind it. Notes keep their formatting, links and step reveals. Click empty space inside the notes window to select Section notes; Delete Section notes removes only the paragraphs and bullets, preserving the section and diagram. Click an individual paragraph or bullet to edit or delete just that item. The window’s × button hides notes temporarily. Adding a paragraph or bullet keeps Explore open and creates the notes window if needed. Standard restores the prose and its previous collapse state. In Explore, drag a panel or notes header, resize its corner or hide it while inspecting the story. Panels & controls has its own minus/plus zoom: shrink the floating content to reveal more of the diagram, or enlarge it for reading. Click its percentage to reset to 100%. The diagram zoom stays independent; the step bar keeps its available horizontal space. In the workbench this scale saves to the selected view with Undo/Redo; reader adjustments remain temporary. Hold Ctrl or Cmd while scrolling over the graph to zoom, or pinch on a trackpad. Plain scrolling pans the graph. Edge legend shows the diagram’s protocol colors, line samples and response/ack key; press Escape to close it. Panels chooses available panels; Hide panels / Restore panels clears or restores them, and Stack at edge returns them to the right side. Expand gives the graph more room. Reader changes do not rewrite your diagram. The editor and exported HTML follow the same View type. In the workbench, panel and step-control positions and sizes save to this view automatically. Full-browser pan and zoom are temporary navigation; choose Back to page to author the opening camera in the contained Explore view. Open Explore returns to the full browser. Each gesture is one Undo action; Escape cancels a drag. Use the small grip on the step bar to move it and its corner to resize it. Drag empty graph space to pan a quarter-screen past each edge. Explore’s Story selector switches top-level diagram sections and appears only when there is more than one. Detail-only domains open through their nodes; use their breadcrumb to return to the overview. Keep Standard as the default business view and use Explore for an engineering view. View type belongs to the named view across all host previews, and duplicating a view keeps it. Changing View type is one Undo/Redo operation. Explore stays visible while arranging. Optimize layout or Reset layout restores its automatic edge stack and diagram sizing while keeping hidden panels hidden. Saved defaults scale to the viewer’s available space.

Under Visible elements, each panel and the data diagram has its own checkbox for the selected layout. Explore also has a Section notes checkbox: this saves notes visibility for that view; the notes window’s Hide button is temporary. Hide Home in the engineering view or hide Data flow in the customer view. Optimize layout arranges the visible elements and respects the hidden set. Make default chooses the opening view. Property edits, Undo/Redo, and host preview changes keep your current view selected. Opening another project uses its own default; deleting the selected view falls back to the remaining default. Done arranging returns to ordinary use.

Attach the step controls to Home or Data flow to keep them in the same outlined frame, or detach them for independent placement. Resize attached controls with their height adjustment. Under Steps shown in this view, select only the stops that audience needs. Skipped steps still happen: their effects carry forward. This shortens the presentation, not the story.

Preview Responsive, Backstage, or Confluence to tune space for the destination. These are layout previews, not live connections to those products. Named views are the complete set of view buttons; create a view named “Data flow” if you want one alongside your other arrangements.

09 / SERVICES & EVIDENCE

Make the picture traceable.

Canon diagrams on the home page opens the published library read-only. You can play steps, switch paths and views, and follow evidence links. A guided tour offers a walkthrough on your first visit; choose the ? button to replay it. Skip or finish the tour to return to reading. On later diagrams, New features to explore offers just the tour topics you have not seen, for your chosen walkthrough. This learning history stays in your browser. Copy link shares a direct read-only URL to a published diagram, even before Backstage is connected. You can also open a library card in a new tab. Edit in Workbench opens a local editable copy. It does not overwrite or approve the canonical source; save your changes and submit them through your team’s repository process. Keep the required JSON spec under diagrams/<name>/; a standalone HTML export is optional. After review, add the folder and its owner to root canon.json. The normal build publishes that list for the workbench; Backstage uses the same membership. Per-spec flags do not enroll a diagram. Saving an editor draft does not change canon membership.

To seed a graph, choose From service catalog on the home page or Add to diagram → Services from catalog. Pick the services you need. Optional connections come from declared dependencies and API relationships. A single connection lists all consumed APIs for that service pair, along with any explicit dependency. Existing connection labels stay as authored. These connections do not establish the runtime ordering of your feature.

On a node, choose Company service, then Service API and API operation where available. Selecting a service fills an empty name but preserves an authored one. The hosted editor loads its bundled catalog automatically. For a manual snapshot, choose File → Company repository, paste catalog JSON, and choose Load catalog.

Code references are a separate authoring task. Use Code and trace evidence on a step to reference the repository, file, and reviewed revision. Viewers can follow those links. A code change is drift evidence, not proof that behavior changed; a person reviews that decision.

For a trace-based starting point, choose File → Import and use the trace importer with pasted or exported trace JSON. Check the observed services and timings before treating it as the intended design. A missing span alone does not prove a failed communication.

To highlight a change, select a node, connection, or step and enable delta (change marker). Under Change details (optional), write a Delta note or use Add delta link to attach supporting pages. Viewers click the green triangle to read the details. Step triangles open details without advancing playback. Press Escape to close.

10 / COPY & REUSE

Choose whether the relationship should stay shared.

Use the toolbar’s Copy, Paste into Section…, and Duplicate for selected nodes, panels, or sections. Copy and Duplicate enable for supported selections; a single step supports Duplicate. Paste stays available without a selection and names its destination section. Multi-select nodes to copy a group; internal connections travel with them when both endpoints are included. A copied section includes its story and alternate paths. A copied panel carries its layout and starting state, not the current step’s animation.

In Home’s shared layout inspector, use Copy element or Duplicate element for its contents. For story events, use Reuse steps…: copying creates an independent event, while sharing deliberately keeps one event on multiple paths. Consecutive shared events can form a common middle block or ending. Check Destination preview to see the state they receive from this path’s earlier steps. Undo reverses an operation as a unit.

⌘/Ctrl C, ⌘/Ctrl V, and ⌘/Ctrl D operate on diagram objects outside text fields. Inside a text field, normal text editing takes priority. If clipboard permission is unavailable, Paste… provides a manual text option.

11 / SAVE & SHARE

Keep the source. Share the experience.

Download JSON
Keep the editable JSON. Open it later to continue authoring.
Brief → Download review package
Download a ZIP containing the diagram JSON, viewer HTML, story notes, and evidence references for human review. This does not publish or submit anything.
export…
Write the JSON and a standalone viewer HTML page to a folder. Share or host the HTML for readers.
Export for Confluence
Download the payload for the Flowview Forge integration.
Copy JSON for Confluence
Copy that payload to paste into the integration’s configuration.
Copy link / Copy embed link
Link to a viewer’s selected section, view, path, and step. Share a hosted viewer URL your readers can reach.

The File workspace reports whether the browser recovery copy was saved or storage is unavailable. Download JSON writes a file to your computer; it does not publish to a repository. The browser draft is convenient recovery, not a repository commit or a backup. Save JSON before clearing browser data or moving computers. Confluence and Backstage publication depend on your company’s integration and access controls; exporting or editing here does not publish to either one.

Take the tour on the homepage walks through a real example, then agent setup and manual editing in an isolated practice project. Returning readers start with the workbench chapters; use the chapter bar to replay the diagram introduction. You can expand the sample and tour to full screen. Practice changes never touch your draft, folder or clipboard. Take the workbench tour is also available in the workbench header and agent setup.

12 / WORK WITH AN AGENT

Your agent talks. The workbench shows the result.

Open Agent on the left rail to see the current connection status, folder and files. There are no tabs. When disconnected, choose Reopen diagram folder for a remembered build or New Connection to choose Copy & paste or In workbench · Beta in setup. Once connected, only that method’s controls appear; your message follows the workbench’s current selection. Keep the diagram and its coverage ledger in one folder. You can return to that folder with another conversation or agent. The ledger records the story plan, evidence, decisions, assumptions and open work so the next conversation can pick up where you left off.

  1. Choose where to talk. From home, open Build with my agent. The shared setup opens with Copy & paste · Recommended selected to keep conversation, questions, permissions and interrupts in your agent’s app. Inside workbench · Beta brings messages into the workbench through Claude Monitor; permissions and interrupts still happen in Claude. Both use the same folder and review process.
  2. Choose how you are starting. Add an agent to this open diagram selects the folder containing its existing spec and coverage ledger, or a different folder for an agent-working copy. Continue an existing agent build selects the durable diagram folder used earlier; Flowview finds .flowview-agent/ inside it. Start a new diagram with an agent requires a new, empty folder. If a folder contains several specs, choose one from the list after selecting the folder. Your previous draft stays in Earlier drafts. The spec and ledger live at the top level; .flowview-agent/ holds connection data and workbench messages. Your agent app keeps its own conversation history.
  3. Paste the setup into your agent. Choose the story detail, review the setup, then use Copy connection instructions. Paste them into an agent with access to the local folder. Copying alone does not send anything. Recommended copy/paste needs no Monitor or background watcher. Give the agent your brief and source material, answer its questions, and have it keep the story plan and decisions in the ledger.
  4. Share selected context. After connecting a diagram folder, select nodes, steps, panels, or other elements using the normal workbench controls, then click Copy for agent · N selected at the bottom left. It briefly shows Copied; paste that context into your agent. No message is required, and your draft and any active request stay as they are. To add a message and register a request for review, open Agent. Its Focus summary follows that selection. In Copy & paste, Copy request includes your message, selected item identifiers and references, view, path, and requested detail. It leaves out the diagram JSON and the contents of selected sections. Your agent reads the full spec and ledger from the connected shared folder. Paste it into your agent’s conversation. In In workbench · Beta, explicitly connect Claude Monitor before using Send to Claude. The Agent panel shows only the controls for your connected method. When disconnected, choose Reopen diagram folder to continue a saved build or New Connection to choose a method and folder. While a connected request is active, an Agent working pill stays in the top project bar; click it to reopen Agent. It also calls out permission and review states, then disappears when the request ends. Clipboard denial exposes a prepared request for manual copying.
  5. Preview before accepting. When the update banner appears, open Preview Agent Updates. Switch between Current state and Proposed state, walk the paths, and expand Coverage ledger below the diagram. Explore stays inside the preview area, with comparison and commit controls available while you navigate the diagram. The ledger starts collapsed and shows whether it changed. Scroll or resize its reading area, then collapse it to give the diagram more room. Back to workbench leaves the update waiting; Discard update rejects it. When ready, Commit update saves the spec and ledger in the diagram folder as one Undo action. Undo and Redo restore both together.
  6. Finish with a matching ledger. Separate edits can merge, so ask your agent to reread the accepted spec and ledger and correct any claims that no longer match. Review a ledger correction the same way. Then ask your agent to prepare the reviewed pair for a repository commit; authorize the Git commit when ready. Commit update approves local artifacts, not a Git commit or publication. Connection data and candidate files stay out of the repository commit.
If both of you changed the same thing. Review conflicts opens the feedback and blocks Commit update. Choose Copy feedback for your agent to copy the explanation and return the proposal for revision. If clipboard access fails, copy the selected feedback manually and choose Return for revision. Paste the feedback into your agent’s conversation and ask it to reread the current spec and ledger, reconcile the changes, and submit a fresh proposal. Independent edits can merge; competing edits to the ledger need reconciliation too.

Keep the request concrete. Say who the diagram is for, the question it should answer, and which outcomes matter. For a new or changed story, expect a short batch of questions about whatever your brief leaves open: takeaway, key moments, time span and starting state. Review the storyboard in the ledger: clocks and batteries should follow time, steps should show every communication they use, and icons should match state.

Explain what happens from a doorbell press to a resident seeing the clip. Include the successful path, a recording timeout with recovery, and an outage that ends early. Give engineers a service view and business readers a Home view of the same steps. Use the attached design as evidence; identify anything it does not establish.

In Copy & paste, Shared folder ready means the folder is connected; no Claude listener is needed. An active request says Continue in your agent. Conversation and progress stay in your agent app. The panel keeps update previews, conflict feedback and collapsed Recent diagram updates.

Using the Beta conversation

The Agent window shows replies and status: waiting, working, permission needed, or changes ready for review. Expand Focus to check selection and view context, or Detail: Story to change the next message’s detail. Sent messages keep their original context. Scrolling up pauses following; New output · Jump to latest resumes it. Use Claude for permissions and interrupts. Stop accepting this turn stops the workbench accepting that turn’s updates; it does not interrupt the agent process.

Need a standalone authoring brief instead?

Choose that option on the Build with my agent page when you want to exchange files manually. Select design, codebase, or an existing diagram; add your brief, choose Who is it for?, and copy the prompt. Using a company fork? changes the toolkit repository and revision. Business readers get story-level detail, with technical decisions recorded in the ledger under “Decisions I made”; engineers get service hops, APIs and code references. Run the agent in your own tools and bring its JSON back with Paste JSON or Open file. This route does not use the shared-folder update banner.

Already using the older local agent session?

The URL from node tools/agent-session.mjs uses a separate scratch-folder protocol. Give the agent that folder’s README. Its proposals apply automatically as one Undo action when editing is idle; it does not use Preview Agent Updates. Finish typing or dragging and click the canvas to let a waiting update apply. File → Local agent session shows its status, and Agent files · Disconnect stops sharing. For the folder and approval workflow above, start from Build with my agent.

13 / WHEN SOMETHING SURPRISES YOU

Usually, it is the editing context.

“Editing the alternate changed the happy path.”
That event is shared. Use Make independent here before changing its content for one path.
“My new branch starts with the same event.”
Create it after the last shared step. The next step is the first independent outcome. The shared lead-in still plays from step 1.
“The camera is still recording on this step.”
State carries forward. Set recording off at the appropriate beat; changing a scene does not automatically end recording.
“I hid a step, but its result is still visible.”
A view skips presentation stops, not their effects. Use an alternate path to change what actually happens.
“I can’t move the house or edit its rooms.”
Choose Edit shared home layout; step editing changes the event rather than the floor plan.
“Clicks keep highlighting things instead of editing them.”
Finish ADD TO STEP or cancel a pending connection with Esc.
“The service dropdown is empty.”
The catalog has not loaded or has no matching services. Check File → Company repository for its status, then import a snapshot if needed.
“The editor or diagram feels squeezed.”
Drag the workspace divider, or choose File → Workspace preferences → Focus workspace. Try Readable size for a wide graph, and arrange the section for the target host.

Start small. Walk every outcome. Let every animation explain a change.
